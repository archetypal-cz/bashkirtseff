## Issues Encountered

### TOOL-BUG: Write tool path tracking (CRITICAL)
The most disruptive issue this run. When a translator agent attempts to `Read` a file that doesn't exist yet, the Write tool permanently blocks that path for the entire agent session.

**Impact**: ~30 minutes of debugging and respawning.
**Workaround**: Pre-create empty placeholder files (`touch`) before spawning translators.

### EDITOR-ACCESS: No Edit access for editor subagent type
Known pattern from previous runs. Editors can Read/Grep/Glob but not Edit or Write. All fixes must be applied by ED based on editor reports.

### FRONTMATTER-COLLISION: Pre-existing `editor_approved: false` in 092
The translator had added `editor_approved: false` and `conductor_approved: false` to some entries. ED's batch `sed` created duplicate keys. Fixed by removing the `false` lines.

### STRAY-CONTENT: English fragment in French comment block (092)
File `1881-07-28.md` had an English translation fragment incorrectly placed inside a `%% ... %%` comment block. Removed during RED review.

### DUPLICATE-IDS: Paragraph ID collisions (091)
Three entries in carnet 091 had heading and first content paragraph sharing the same ID. Fixed during translation phase.

## Observations

### Quality Patterns
- **Register is the #1 issue**: Most fixes were register-related — words technically correct but wrong for Marie's 1880s voice or context (medical "immune" vs neutral "subject to", adult "minx" for a 9-year-old, modern "bloody" vs period "vile").
- **French word-order calques are #2**: Translators occasionally preserved French syntax ("make oneself beautiful only to have..." instead of natural English "dress up only to have...").
- **Longer carnets scored lower**: 096 (90 entries, 0.86) and 092 (96 entries, 0.87) vs shorter 103 (59 entries, 0.92) and 102 (88 entries, 0.93). May benefit from mid-carnet context refreshes.
