## Lessons / New Defect Patterns (for WATCHLIST + skills)

1. **`%%`-balance defect family (translator) — now characterized.** Three variants, all caught by
   `verify-carnet`'s `%%-balance`, none reaching review:
   (a) inline mid-paragraph source tag wrapped into a 3-`%%` line (090 coda);
   (b) multi-line French verse where only the last line closes its comment (098 Musset);
   (c) footnote *definition* wrapped inside a `%%` comment → invisible to renderer AND footnote
   checker, leaving a live ref with no def (087, first-agent artifact).
   **Fix applied this wave:** translator spawn prompt hardened with all three rules; after the
   hardening, every fresh carnet passed the gate first-try.
2. **CON/RED can break `%%`-balance by typing a literal `%%` in comment prose** (098 CON wrote
   "%%-balanced" in its verdict). **Lesson: re-verify after CON, not only after TR/RED** — adopted
   for the rest of the wave; caught it pre-push. Reviewer prompts now say "write 'marker-balanced',
   never the symbol."
3. **`check-links-repo` exit code is unreliable as a pre-commit gate when another language is being
   edited concurrently.** A parallel CZ session left ~740 broken links in `cz/` for much of this
   run (the classic translator path-depth drift). Switched the pre-commit gate to grep the **`uk:`
   line specifically** (always 0). Flagged the CZ breakage to the operator; left CZ untouched.
4. **Stall-watcher false positives** after a restart: comparing "now − newest mtime" trips
   immediately on pre-restart files. Corrected to a baseline ("no writes since watcher start").
5. **Per-carnet "Paul" referent is highly context-dependent and era-specific** — Cassagnac (1879–82
   default), the brother, the father (1884), and even Rodolphe Julian (087/084 atelier gossip). Each
   carnet's TR disambiguated per-occurrence; RED/CON verified. No single rule works corpus-wide.
