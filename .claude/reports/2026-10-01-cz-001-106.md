# cz post-rebuild translation wave, 001–106

## Scope and result

After the source-restoration rebuild (`_original` had lacked ~13% of the manuscript text), the cz tree held ~6,300 `TODO` paragraphs/headings, several hundred `SOURCE CHANGED` notes from the resync and ~2,000 entries with reset flags.

**Result:** 0 `TODO`, 0 unresolved `SOURCE CHANGED` notes, and all 4,274 entry files `conductor_approved: true`. `verify-carnet` PASS and `splicescan` empty on every carnet, `check-links-repo` 0 broken. 160 `(cz)` commits from 32a46554d (2026-09-29) on; one commit per carnet plus sweep commits. Tracker: `~/rebuild-state/wave/cz.md`.

CON scores (Opus) held at the cz plateau, 0.88–0.92 per range. RED (Sonnet, 090–106) self-scored 0.78–0.93 *before* its own fixes; the late carnets 100, 103, 104 and 105 were the weakest (pre-fix 0.78–0.84).

## Configuration

- One Opus driver (this session) orchestrated background agents. Each date-range batch went through `translator` → `editor` → `conductor`. A carnet with more than ~150 TODO lines was split into 2–4 date ranges running in parallel (different files). At most 3 carnets were in flight.
- Prompt templates live in `~/rebuild-state/wave/prompts/`: tr_range / red_range / con_range, plus seam_cz, fn_cz, leftovers_cz, prompt_fixup_cz. Gate script `gate_cz.sh` reports verify, splicescan, a short-paragraph ratio (<0.4 of a French paragraph over 250 chars), TODO, srcchg, unRED and unCON. Commits ran through `commit_cz.sh` / `commit_sweep.sh` under `MAIN_WRITE_LOCK`, with explicit paths only.
- Addendum 3 (2026-10-01 17:10): TR and RED moved to Sonnet 5.5, CON stayed on Opus.

## Agent lifecycle

- Spend and session limits stopped the wave three times. Each time it was recovered from disk: re-gate, then relaunch TR only on remaining TODO lines and RED only on unapproved files. No work was lost.
- The shared concurrent-subagent cap (20, shared with the uk/en drivers and fix-source) was hit a few times; the agents were relaunched later.
- Parallel agents overwrote each other's helper scripts in the shared scratchpad (098 CON, 100 RED). Both noticed and re-ran their own edits. **Lesson:** tell workers to name scratch files with carnet + range.
- One CON agent edited a file outside its range (105/07-11, a «c'est égal» fix). That was harmless and is flagged in the file.
- No agent got stuck. Typical durations: Sonnet TR 1.5–6 min, Sonnet RED 3–15 min, Opus CON 3–16 min per batch.

## Issues encountered (WATCHLIST categories)

- **Shared-checkout commit sweep:** fix-source's commit c1606c511 ("carry 003-084 paragraph joins") staged `content/cz` broadly. It swept in my uncommitted 092/093 CON work and a label sweep. Nothing was lost, but the text went live under the wrong message. My own label-sweep script nearly did the same to fix-source's cz/021 work; I caught it from `git diff --stat` before it took the lock. **Rule:** sweep commits must `git add` explicit files, never a carnet directory, while others work in the tree.
- **Flags without a review trail:** the independent review found 64 rebuild-reset entries (002, 005, 010, 012, 021, 028, 030, 064, 085, 104) that were `conductor_approved: true` with no CON comment after the reset. Their carnet commits said TR+RED+CON. They got a real CON pass (0.91–0.92, fixes made, 93752485e). Date-only stubs approved without a comment (149) are accepted as low risk. **Lesson:** the gate should check that a CON comment exists after the last ED reset note, not only the flag.
- **Rebuild leftovers in the translation:** 100–105 had old Czech text from neighbouring days merged into the wrong date files, and some summary placeholders («[Obsah záznamu chybí…]»). TR trimmed and retranslated these. The ratio column in the gate found them; the flags never would have.
- **RED regressions caught by CON:** wrong stub wording, «Záhadný» → «Překvapivý», Collignonová, Cassagnak-, «jsem zdráv» (a feminine note-writer), and «pope» rendered as „pravoslavný kněz". CON reverted each one. Sonnet RED also left a file's flag unset while reporting it approved (099/04-28), and in another case reported a label conversion "not needed" while the carnet was left mixed (094).
- **Source defects** went one line each into `~/rebuild-state/source-issues.md` (`(wave-cz)`), about 25 lines: OCR «II»/«I!» for «!!», glued «Mots noircis» labels, misdated headings, footnote facts (Andrieux/Aragon, Madrazo, Bojidar "sculptor", Isabella II).

## Open for the owner / lead

- Frontend language marker: `paragraph-kind.ts` only matches „V originále anglicky". The run convention („Tento a N následujících odstavců psala Marie anglicky.", one note on the first paragraph of each run) leaves ~80 English paragraphs without a marker on the site. The lead has been asked.
- Name forms that are unlocked or in conflict: Mussia vs Moussia; «la maréchale» (maršálová 33 / maršálka 35 / maréchála 9); Karagjorgjevič vs Karađorđevič (101); Čumakov vs Tchoumakoff; Tchernitská vs Černická; Cassagnac declension; Saint Amand vs Saint-Amand; Jurkov (031–049) vs Yourkoff.
- Content-less struck/blacked labels („[Škrtnutá slova]", „[Tři řádky škrtnuty]", „Smazáno" for «Effacé»): there is no lock for these.
- Straight closing quotes (`"`) are common in 098–106. That is corpus-wide cosmetic work, not done.

## Proposed changes

1. **ED skill / gate:** add a "CON trail after the last reset" check, so that `conductor_approved` without a later CON comment fails.
2. **ED skill:** sweep commits stage explicit file lists. A worker prompt must name scratch files uniquely (carnet + range).
3. **editor skill (Sonnet RED):** verify every changed file's flag before reporting. Treat TM name/label locks as mandatory, not "left for consistency".
4. **Wave brief template:** include the full list of locked labels and the stub form in every TR prompt. Most churn in this wave came from label variants introduced in earlier waves.
