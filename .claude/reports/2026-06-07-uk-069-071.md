## Proposed Changes

1. **Promote proper-noun consistency to a mechanical check (re-proposed from 065–068).** Two waves running, the dominant defect class is valid-Cyrillic proper-noun drift (Олександр/Алессандро/uncle, Башкирцев/Башкірцев, ніццянці/ніццяни, Ерістов/Еристов) — invisible to `verify-carnet`, caught only by alert RED/CON. A TM-locked-name lint (flag a pinned name appearing in a valid-but-non-canonical spelling, with per-carnet allow-list for legitimate homographs like the saint/pope «Олександр») would move this class to the gate. This is now the clear top recommendation across both waves.
2. **CON/RED scope-counting gate.** CON twice nearly mis-scoped by inferring the entry set from the date sequence. Add to the conductor + editor skills: "Before starting, run `ls content/{lang}/{carnet}/*.md | wc -l` and reconcile against the task's stated entry count; review against the file list, not a date range." (red-2 was given this instruction explicitly this wave and had no miss.)
3. **Verify mechanical agent claims (reinforced).** red-2's report asserted a name state (069.0240 = «Олександра») that disk contradicted (already «Алессандро»). Team-lead's pre-handoff grep caught it. Keep the standing rule: confirm any checkable agent claim against disk before acting/reporting.
