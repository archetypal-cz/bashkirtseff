## Issues Encountered

1. **Translators finish-but-don't-finalize (recurring, NEW pattern, WATCHLIST candidate).**
   See lifecycle above. 4/6 translators idled after writing all files + setting
   `translation_complete: true` but before `TaskUpdate status=completed` + summary. Likely the
   manual self-review pass (Phase 3) ends and the agent idles rather than doing the final
   bookkeeping. Mitigation that worked: ED watches disk (`translation_complete` counts) and
   nudges. Better fix: translator skill should make "mark task complete + send summary" the
   explicit final step *after* self-review, called out as a distinct action.

2. **One-team-per-leader blocks clean wave separation.** Couldn't create a `uk-036-041` team
   while still leading `uk-031-035`, so wave 8 reused the wave-7 team + task list (tasks
   #16-33). Cosmetic only (reports are split by carnet range regardless), but worth noting for
   anyone expecting one-team-per-wave.

3. **Deferred TM terms need ED follow-up.** tr-040 (correctly) declined to edit
   TranslationMemory.md while siblings were active, flagging its terms for the ED instead.
   Those terms (Kechko, de Gonzales, Romanoff lawsuit vocab, etc.) were folded into TM
   post-wave by the ED. tr-041's minor terms were absorbed into existing entries. Good
   instinct on the translator's part; just needs the ED to actually fold them in at wave end
   (done).

4. **Idle poll-loops** from review agents persisted intermittently despite "wait for ping"
   spawn instructions — lower volume than wave 7 but still present.

## Proposed Changes

1. **translator/SKILL.md**: make the final bookkeeping an explicit, named step — "After
   self-review, you MUST: (1) mark your TR task complete via TaskUpdate, (2) send the team lead
   a summary, (3) then stop. Setting translation_complete in frontmatter is NOT the same as
   marking the task complete." Directly addresses the wave-8 finish-but-don't-finalize pattern.
2. **executive-director/SKILL.md**: codify "watch disk state, not just task state" — translators
   may finish files before finalizing tasks; check `translation_complete` counts and nudge.
   (Pairs with the wave-7 "verify on disk after session interruption" note.)
3. **translator/SKILL.md**: add a one-liner that when a translator can't safely edit
   TranslationMemory.md (siblings active), it should flag new terms to the ED for folding-in,
   as tr-040 did — make the good instinct the documented norm.
4. Reaffirm wave-7's proposals (manual self-review note; review-agent "wait for ping" default)
   — both still relevant this wave.
