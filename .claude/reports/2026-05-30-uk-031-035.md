## Issues Encountered

1. **Grammar-critic subagent gap (recurring, WATCHLIST-relevant).** The translator skill's
   Phase 3 self-review calls for spawning an Opus grammar/naturalness critic *subagent*.
   Teammates spawned via the Agent tool do **not** have Agent/Task tools, so translators
   cannot do this. tr-035 surfaced it; all translators fell back to a careful **manual**
   self-review, which produced 0.953–0.957 quality. Mitigation applied mid-wave: I baked
   "do a manual self-review, you have no Agent tool" into every subsequent translator spawn
   prompt so no one stalled waiting on a capability they lack.

2. **Idle poll-loops from review agents.** RED and CON, when their tasks were blocked,
   woke/checked TaskList/re-idled every ~20–30s, generating churn. Mitigation: instructed
   both to wait passively and rely on team-lead pings rather than polling. This cleaned up
   the noise substantially. Worth baking the "wait for ping, don't poll" instruction into
   review-agent spawn prompts by default.

3. **Session pause dropped a ping.** A ~2.5h session gap (06:47→09:17) appears to have
   dropped my CON ping for carnet 032 — CON #15 sat pending with 0 conductor_approved while
   all 24 entries were editor_approved. Caught it by checking disk state (conductor_approved
   count) rather than trusting the message log. Re-pinged; CON completed normally (0.957).
   Lesson: verify pipeline state on disk after any session interruption, don't assume
   in-flight messages survived.

4. **Translator shutdown confirmations occasionally lagged** through the session pause
   (red's shutdown_approved didn't arrive; it lingered idle in the roster). Harmless but
   required a re-confirm.
