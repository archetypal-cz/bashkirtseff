## Issues Encountered

### CRITICAL: Source Mismatch in Carnet 062 (June 1-6)
**Category**: Data integrity / translator hallucination

The translator (tr-000-2) translated 6 entries from a **different French text** than what exists in `_original/062/`. The embedded French in the translation files did not match the actual originals. Investigation confirmed:
- 4 entries matched (May 29-31, June 7)
- 6 entries mismatched (June 1-6) — completely different paragraphs

**Root cause**: Unknown. Possible explanations:
1. Translator used cached/hallucinated French text
2. Source files were restructured after translator read them
3. Translator mixed up with a secondary source

**Resolution**: tr-fix agent retranslated all 6 entries from correct source. RED-062-fix verified source alignment. CON approved at 0.955.

**Recommendation**: Add source verification step to RED skill — compare embedded French with originals as standard check.

### Editor Subagent Lacks Edit Access
**Category**: WATCHLIST — recurring

Editor (`editor` subagent type) cannot write files. ED must apply all RED fixes manually. This has been observed in every run since 2026-02-27.

**Workaround**: ED applies fixes via Edit tool + batch sed for editor_approved flags.

### Duplicate Frontmatter Lines
**Category**: Technical / sed artifact

Using `sed -i 's/^translation_complete: true$/...\neditor_approved: true/'` on files that already had `editor_approved: false` created duplicate lines. Required cleanup pass.

**Fix**: Check for existing `editor_approved` before inserting, or use `sed` to replace `false` with `true` instead of inserting new lines.
