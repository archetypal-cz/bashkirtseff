## Issues Encountered

1. **CON false-start / pre-claim churn (process)** — con2 pre-claimed CON tasks and treated their pending state as actionable, repeatedly reporting "carnet not ready." Fixed mid-run with a strict ping-phrase protocol. **Skill-worthy**: review agents should NOT pre-claim blocked tasks, and should act only on an explicit lead ping, not board state.
2. **Cross-carnet naming drift (recurring, all caught)** — same-referent terms diverged between translators: Belle-de-Jour (Денна Красуня vs Красень-Денний), Cimiez (Сіме vs Чимієз), la Pointue (Гострячка / Гоструха vs Гостра), l'Olive (Оліва vs Оливка), the servant "petit nègre" (негреня vs чорний хлопчик), «голена» vs «Голена Сорока». All normalized by red2/con2/translators to the first-approved form; TM updated with the canonical choices + a reusable-epithet note for «Сорока».
3. **ED misread → averted mistranslation** — ED initially read tr-054's summary as a Troili=«Сорока» collision and asked red2 to "fix" it. red2 verified against the source: «Сорока» is Marie's *generic* magpie pet-word reused for different men across carnets (Audiffret in 052, Giorgio the gardener in 054); Troili is «Тройлі»/«Ґалула». Changing it would have mistranslated. ED reverted the instruction and corrected TM. **Lesson: verify cross-carnet "collisions" against the source before normalizing — some are authorial reuse, not errors.**
4. **Frontmatter schema inconsistency (3 shapes in one wave)** — 051-054 flat top-level; 055 nested `workflow:`; 050 hybrid (flags top-level but a workflow: block present for research/LAN/kernberger). red2/con2 detected per-carnet and matched indentation, YAML-validating after each. No breakage, but confirms the wave-1 finding that flag-writers must detect structure, not assume.
5. **One polarity reversal caught (055.1041)** — «ne m'en fiche pas mal» (= NOT indifferent) had been rendered as indifferent; red2 fixed to «не байдуже». The negated `se ficher` idiom against the affirmative ones elsewhere — a classic trap. (050's three `se ficher` instances were all checked and correct.)
6. **Source-side metadata (not a UK defect)** — 053 French originals for 02-08/02-10 carry wrong `location` (Vienna/Paris) for Rome entries. Does NOT propagate to UK files (which have no location field). Logged for source maintenance.

## Observations

- **Spawn-prompt terminology injection continues to be the highest-leverage control** — first-pass terminology was clean for nearly all carnets; the residual drift was on *new* same-referent epithets that emerged mid-wave (resolved by red2 normalization + TM updates), not the locked conventions.
- **red2's proactive cross-carnet reconciliation** (normalizing to first-approved forms and flagging the rest) was the quality engine of this wave — it caught drift the translators couldn't see in isolation.
- **Disk-state checks again caught silent finishes** (translators idle-before-report) and let ED pre-verify terminology before routing, offloading bulk normalizations (e.g. 050's 16 la-Pointue forms) to the warm translator instead of the reviewer.
- Quality rose with literary demand: 055 (the declaration scenes + stichomythia) scored highest at 0.95.

## Proposed Changes

1. **conductor/editor SKILL**: "Do NOT pre-claim blocked review tasks, and do NOT treat a pending task on the board as a signal to act. Act only when the team lead sends an explicit per-carnet review ping." (Directly addresses con2's churn.)
2. **executive-director SKILL**: codify "verify cross-carnet term 'collisions' against the source before ordering a normalization — distinguish translator drift (normalize) from Marie's authorial reuse (keep + footnote)." (The Сорока episode.)
3. **Shared frontmatter guidance**: document the THREE observed shapes (flat / nested `workflow:` / hybrid); flag-writers must detect and match per file + YAML-validate. (Reinforces wave-1 note.)
4. **translator SKILL / TM**: keep appending canonical forms for recurring epithets as they're coined, so later translators in the same arc inherit them (Belle-de-Jour, la Pointue, Сорока-as-reusable-epithet, the Rome cast all added this wave).
