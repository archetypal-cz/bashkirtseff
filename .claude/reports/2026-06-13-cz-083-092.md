## Issues Encountered

1. **Blank entry slipped TR self-review (084/1879-03-27).** tr-h reported
   "101/101, checks passed" but one entry was a 0-byte file. The pre-RED
   `verify-carnet` gate caught it (frontmatter + %%-balance FAIL). Bounced back
   to the still-alive translator, re-translated, re-gated clean. **The gate is
   the real safety net; translator self-reports are not sufficient.**
2. **Systemic tool-leakage artifact (086).** All 100 cz/086 files ended with a
   stray `</content>` tag (one also `</invoke>`) — a TR/tool artifact RED did not
   strip. CON (con-7) caught and stripped it. **This is a gate blind spot:**
   `verify-carnet` PASSED because the tag is not a `%%`/link/frontmatter defect.
   A wave-wide sweep confirmed the artifact was isolated to 086; the 6
   already-committed carnets were clean (nothing reached production). For the
   remaining carnets, a stray-tag sweep was added to the pre-RED gate manually.
3. **Self-inflicted `%%` in a TR comment (084/1879-01-18).** A translator's own
   TR comment contained the literal sequence `%%`, unbalancing the file. Caught
   by gate, fixed.
4. **Recurring 1st-person gender/agreement errors.** French gender-neutral
   participles/"on" repeatedly got masculine or 3pl Czech forms where Marie is
   the (feminine, singular) subject — incl. a přechodník (maje→majíc) that even
   RED missed and CON caught. Now a locked TM checklist item.

## Proposed Changes

1. **Teach `verify-carnet` to flag stray non-content tags** (`</content>`,
   `</invoke>`, `antml:*`, dangling `</…>`) at end-of-file / anywhere in body.
   This is a recurring TR tool-leakage class that currently passes the gate and
   relies on a human/CON reading-catch (the 086 case would have shipped 100
   polluted files otherwise). Add it as a hard check.
2. **Add a translator post-write self-gate reminder** that file count == source
   count AND no 0-byte files, since TR self-reports claimed completeness while a
   blank entry existed (084).
3. **Lock the 1st-person feminine-agreement check** into the editor skill's
   Czech trap table (grep masculine past-tense / "rád" / 3pl + přechodník forms
   in 1st-person contexts) — it recurred across carnets and one instance reached
   CON.
4. **Forbid the literal `%%` sequence inside comment text** in the translator
   skill (use "%-značky" or similar) — it unbalanced a file (084).
5. Per-carnet `cz/NNN/README.md` files were not generated by `just scaffold`;
   consider adding them (flagged by con-5; non-blocking, deferred).
