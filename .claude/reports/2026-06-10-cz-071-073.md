## Issues Encountered

**Recurring TR defect classes (flagged by RED across ALL THREE carnets):**

1. **Source-block contamination (Latin-script).** Czech words leaked into the preserved
   French `%% … %%` original/RSR/LAN comment blocks: e.g. `en bílém a`→`en blanc et`,
   `dva jours`→`deux jours`, `à Paříži`→`à Paris`. **11 instances total** across 071/072
   (3 + 6 + 2). This class is **invisible to `verify-carnet`** (latin-in-cyr only catches
   Cyrillic; these are Latin-script Czech words in French lines) and slips past a naturalness
   read. CON-072 caught one RED had missed via a targeted diacritic scan (ě/ř/ů/č/š/ž/ý)
   over every `%% %%` block — that scan should be standardized.
2. **Noun-gender / case agreement.** ~25 (071), ~20 (072), several (073). Gender slips
   (`Ten Paříž`→`Ta Paříž`, `takový touha`→`taková touha`) and accusative-vs-dative on
   person-name direct objects (`Alexandrovi`/`Lardereiovi` dative where accusative `-a`
   was needed).
3. **Meaning reversals/inversions.** 071: "lost a mistress" vs "just fell in love",
   dropped negation ("kdyby pršelo" missing the *ne-*), "tear apart" vs "cheer up".
   072: "Pas encore couchée!" rendered as "still not looking" (inverted). 5 critical
   total, all caught by RED.
4. **1sg verb forms / calques.** `plačem`→`pláču`, `m'enrage`→`rozzuřuje` (not `zuří`,
   intransitive), `moisir`→`plesnivět`.
5. **Structural (rare):** one stale-format paragraph ID `10.0126` in cz/073 (the migrated
   carnet) — TR copied an old ID form for one paragraph; RED fixed to `073.0126`.

**No frontmatter-strip / glossary-path-depth defects this round** — translators emitted
correct `../../_original/_glossary/…` paths (cz: 0 broken in check-links-repo).

  diacritic scan reliably catches it.

## Proposed Changes

1. **Add a Latin-script source-block contamination check to `verify-carnet`** (or a new
   sub-check): scan every `%% … %%` French/RSR/LAN comment line for Czech-only diacritics
   (ě/ř/ů/ý and bigrams) and flag. 11 instances/2 carnets this round; the gate currently
   cannot see them. This is the round's strongest skill-evolution signal.
2. **Translator skill:** add an explicit reminder that preserved French `%% %%` source/RSR/LAN
   lines must be copied verbatim, never partially translated — with the diacritic self-check.
3. **Translator skill:** reinforce Czech person-name **accusative vs dative** for direct
   objects (Alexandre/Larderei paradigm) and 1sg verb forms (`pláču` not `plačem`).
