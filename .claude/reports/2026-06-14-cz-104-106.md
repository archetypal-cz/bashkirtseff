## Proposed Changes

1. **WATCHLIST (NEW): never build `%%`-bearing comment text via `printf` format
   strings** — printf eats `%%`→`%` and unbalances the file. Use `printf '%s'`,
   a heredoc, or the Edit tool directly. (104 CON, gate-caught.) If it recurs,
   one-line note to the editor/conductor skills.
2. **Architect / scaffold:** for oversized single-entry files where glossary tags
   live inside the `%%` source blocks, scaffold should emit translation-depth
   paths (`../../_original/_glossary/`) like it does elsewhere — would have
   pre-empted the 196-failure batch. (Joins the standing scaffold/gate set.)
3. **Translator skill (consider): oversized-entry output-discipline note** — for
   any single entry >~150 paragraphs, work in batches, save incrementally, and
   keep assistant narration minimal (the binding limit is OUTPUT tokens). This is
   the concrete mitigation for the long-standing oversized-entry WATCHLIST item;
   2nd hard instance now (uk-056-061 was the 1st).
