## Issues Encountered

1. **Rate-limit pause/resume mid-run** (session resilience). The session hit limits (~21:55 → ~06:16 gap). On resume, **red and tr-6 woke but idled without resuming work** — vague "continue" nudges were insufficient. **What worked**: sending each a concrete, explicit file-by-file checklist (the 17 outstanding entries by name) forced engagement immediately. *Lesson: after a resume, nudge stalled agents with explicit remaining-item lists, not "continue where you left off."* Disk-state checks (not task-board state) were essential to see true progress.

2. **Glossary-link path-depth defect** (silent, caught by ED, missed by RED+CON). Two translators (tr-5/055, tr-6/050) copied source glossary paths `](../_glossary/…)` verbatim without adjusting for the `cz/` directory depth — correct path is `](../../_original/_glossary/…)`. This broke **1,515 links across 65 entries** (946 in 055, 569 in 050). It is invisible to a reading review (the link text looks fine) and **slipped past both RED and CON on 055**; ED caught it via a link-resolution grep prompted by a CON style observation. Bulk-fixed with sed, verified all resolve. *Proposed: add a `just`-level glossary-link resolution check to the RED checklist, or a pre-commit hook. tr-1…tr-4 got the path right, so it's translator-dependent, not systemic to the skill — but a mechanical check would catch it regardless.*

3. **Parallel-edit near-collision on 050** (coordination). RED began reviewing 050 while tr-6 was still running a dialogue-punctuation pass on the same early files (overlap at 12-05). tr-6 flagged it proactively; ED issued a HOLD to RED. Because both used line-level Edit (not full-file Write), the concurrent edits to different lines coexisted without data loss — verified on disk (red's 3 grammar fixes + tr-6's quote conversions all present, 0 corruption). *Lesson: a translator's post-convention cleanup pass and RED review must not run on the same carnet concurrently; serialize them.*

4. **Dialogue-quote convention inconsistency** (cross-carnet style). The house style across 49 prior carnets + 5 of this batch is Czech curly quotes „…". **053 (tr-4) was the lone outlier** with 31 line-start em-dash dialogue lines. Notably, both RED and CON *misidentified 051 as the outlier* — disk grep proved it was 053. Operator chose to harmonize now; quotefix converted 053 to curly quotes. *Lesson: trust the grep over agent recollection for mechanical-consistency questions; consider stating the curly-quote convention explicitly in the translator spawn prompt (done mid-run for tr-4/5/6, but tr-5/tr-6 early drafts still needed conversion).*

5. **Project-wide broken glossary link: `MUSIC_THEME.md`** (out of scope, flagged repeatedly by RED/CON). Tags reference `_glossary/culture/themes/MUSIC_THEME.md` but the actual file is `MUSIC.md` — **2,722 files** project-wide reference the wrong name. This predates this batch and is correctly NOT patched per-carnet (would diverge cz from source convention). **Needs an architect/source-level fix**: either rename `MUSIC.md` → `MUSIC_THEME.md` (matches the 2,722 references) or retarget all references to `MUSIC.md`.

6. **Stale source metadata** (source-side, preserved faithfully). Several 053 entries have wrong `location` frontmatter (Nice/Vienna/Paris on Rome-content entries). Source transcription artifacts ("le manieur"→le malheur, "mes Gâces"→mes Grâces in 053; garbled letter heading in 055; Marie's own birthday-month contradiction in 050.0420) were translated by sense / preserved with TR notes, not silently "corrected." Good practice; worth a later source-side cleanup pass on the 053 locations.

## Observations

- **Quality was consistent and on-bar** (0.93–0.94, avg 0.933) — slightly below the UK 050–055 run's 0.942 but within normal variance; CON noted CZ carnets here trended a touch lower only because the source material (calumny anguish + elaborate satire interleaved) is genuinely hard, and the Czech sustained both registers without melodrama.
- **Terminology coordination via TranslationMemory.md worked** — tr-2 proactively aligned "le Surprenant→Záhadný" to tr-1's choice; the one miss (tr-3's "Překvapivý") was a concurrency artifact (drafted before tr-1's TM update propagated) and RED caught it. ED centralized the `cardinalino` term when translators avoided concurrent TM edits.
- **The editor pass earned its keep**: the critical 052 time error and the 053 polarity inversion would both have shipped without RED.
- **The most valuable ED contribution this run was non-linguistic**: catching the 1,515 broken glossary links that two reviewers missed. A reading review does not catch broken-but-plausible link paths — a mechanical resolver does.

## Proposed Changes

1. **Add a glossary-link resolution check to the RED checklist and/or a `just` recipe** (e.g. `just check-links {lang} {carnet}`) that flags any `](…_glossary/…)` whose target file doesn't exist from the file's location. Would have caught Issues #2 and #5 automatically.
2. **Translator skill: state the dialogue-quote convention explicitly** ("Czech curly quotes „…" for direct speech; never line-start em-dashes in body text") so new translators don't replicate the source's dash style.
3. **ED skill / resilience section: after a session resume, nudge stalled agents with explicit remaining-item lists** (by filename), and verify progress via disk state, not the task board.
4. **Serialize translator cleanup passes and RED review** on the same carnet — never concurrent.
5. **Refresh stale carnet README status tables** (showed 0/N research despite complete RSR/LAN) and fix 053 source `location` frontmatter — minor source-side housekeeping.
6. Escalate the **`MUSIC_THEME.md`** project-wide link fix to an architect/source pass.
