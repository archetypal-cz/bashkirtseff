## Issues Encountered

### RED Editor Lacks Edit Access (KNOWN)
- **Category**: Agent tool limitation
- **Impact**: RED cannot apply fixes or set frontmatter flags
- **Mitigation**: ED dispatched fix subagents for HIGH issues; CON applied MEDIUM/LOW during combined pass
- **Recommendation**: Continue spawning RED as `editor` type for review quality, but plan for ED fix dispatches. Alternatively, test spawning RED as `general-purpose` with editor skill instructions.

### Translator Context Exhaustion After First Carnet
- **Category**: Agent lifecycle
- **Impact**: tr-000, tr-002 could not start second carnet after completing first
- **Mitigation**: Fresh agents spawned for each new carnet
- **Recommendation**: The "one carnet per agent lifecycle" pattern is confirmed. Always spawn fresh agents for new carnets. Do not attempt to reuse translators.

### Write Tool Guard on New Files (tr-003)
- **Category**: Agent tool limitation
- **Impact**: Translator subagent type could not create new files (Write requires prior Read of the path)
- **Notes**: This blocked tr-003 on 068 after completing 070. General-purpose agents (tr-007) did not have this issue.
- **Recommendation**: Consider spawning translators as `general-purpose` with translator skill instructions, similar to CON pattern.

### Translator Overlap / Redundant Spawns
- **Category**: Coordination
- **Impact**: tr-004 and tr-006 were spawned as replacements but found work already done
- **Mitigation**: Minimal cost — agents checked, found nothing to do, shut down
- **Recommendation**: Before spawning replacement, verify the original agent is truly dead (not just slow). Check file count AND send a ping with short timeout.
