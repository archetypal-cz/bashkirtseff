## Issues Encountered

1. **Footnote mis-numbering (gate-caught, WATCHLIST: structural-defect class).** 079/1878-03-27
   had a footnote definition mis-numbered `[^079.127.2]` instead of `[^079.128.1]`, producing
   *both* a duplicate-definition error and an orphan-reference error from one bad line. Invisible
   to a reading review; `just verify-carnet` caught it pre-RED; bounced to tr-079, fixed with a
   single-line edit, re-gated PASS. The pre-RED integrity gate did exactly its job.

2. **`intriguer` false-friend (cross-carnet semantic error).** Czech neologism "intrikovat"
   means *to scheme/plot* — the OPPOSITE of French "intriguer qqn" in the masked-ball/social
   sense (*to intrigue/mystify/pique curiosity*). Present in all three carnets of this wave
   (077/1878-01-27, 078 ×3, 079/1878-03-24) AND in already-committed 074–077 (075/1877-10-20).
   CON identified it during 078 review and locked the form: **intriguer (mystify sense) →
   poplést / zaujmout / zmást, NEVER intrikovat.** Fixed wave-wide; the genuine scheme-sense
   occurrences (079.0516 "více intrik", "pletichy" wordplay) correctly left intact.
   **Open propagation:** 075/1877-10-20 still carries the false-friend — left untouched this
   session (out of scope: already-committed carnet, not part of this wave's commit). Flagged
   for a follow-up propagation pass into 074–077.

3. **TR types Czech into the `%%` French-source block (process note, 2 instances in 077).**
   077.0482 "tout říci", 077.0596 "entendu říci" — the Czech *translation* was correct; only
   the preserved reference-French had a Czech word typed in mid-draft. CON caught both. Same
   class as the body↔source contamination RED catches, but in the source-preservation block.

4. **Single-writer write-race (benign, observed twice).** Both red-077 and the translators did
   idle-wake edit turns *after* their shutdown requests, overlapping the moment their carnet was
   handed to the next stage. On 077, red-077's "dobírat si" intriguer edit and CON's concurrent
   pass diverged (CON read bare "dobírat", changed to "poplést"); the line landed on the value we
   wanted ("poplést", per the lock), so net-benign — but it is a real lost-update hazard. The
   one-writer-per-carnet serialization held in effect only because each overlap happened to be
   idempotent or convergent. See Proposed Changes.

## Observations

  not "Breslauová"), Popaul (kept, not "Pavlík"), and the Paul-brother-vs-Cassagnac collision
  in-draft, so RED/CON spent their budget on genuine meaning/grammar rather than name cleanup.
- **RED catches remained the meaning-critical layer:** 3 polarity reversals across the wave
  (077 "neporušil", 079 04-18), agent flips ("je lui vole"), a localization error
  ("méridional"→"Jihočech"/South-Bohemian), and dîner/oběd (lunch-for-dinner) slips.
- **CON catches were substantive, not just polish:** manchon→rukávník (a fur muff mistranslated
  as a whip, with the footnote also wrong), plus leaked French interjections and source-block
  contaminations.

  conversions per carnet. This is repetitive RED work that a pre-pass script could remove.
- Quality trend: 0.92–0.93, consistent with the 074–076 wave (0.90–0.93). The Paris/atelier
  arc translated cleanly; no carnet needed translator revision after RED.

## Decisions Logged (locked for the wave)

- **intriguer (mystify) → poplést / zaujmout / zmást, NEVER intrikovat.** Propagate to 074–077.
- **Cassagnac declension:** bare surname fully declined (na Cassagnace, s Cassagnacem); formal
  "pan de Cassagnac" keeps particle+name uninflected after "pan". No back-propagation needed.
- **Breslau** — uninflected female surname (Marie writes the bare surname); fem. agreement.
- **Suissesses → Švýcarky** (neutral) as wave default; the lone 078.0090 "Švýcarkaček"
  diminutive left as context-motivated contempt (not normalized).
- **Alexandre oblique stem** differs per carnet (078 "Alexander-", 079 "Alexandr-"); each
  internally consistent; not force-normalized. Watchlist for a future uniformity pass
  ("Alexandr-" the more standard stem).

## Proposed Changes

1. **Quote-normalization pre-pass.** Add/lockfile a mechanical ASCII→Czech-curly quote fixer to
   run on a carnet right after translation_complete and before RED (or fold into `verify-carnet`
   as an autofix). ~75 quote edits this wave were pure mechanical RED time.
2. **`intrikovat` lint.** Add a cheap grep check (translator self-check + optionally verify-carnet
   warn) flagging body-text "intrik*" near masked-ball/social context, given it's now a known
   recurring false-friend. Carry the locked gloss in TranslationMemory (added this session).
3. **Reinforce idle-wake single-writer guard.** The skill already says "shut the translator down
   at the moment you hand its carnet to RED." This wave shows the *editor→CON* handoff has the
   same hazard: red-077 edited post-shutdown-request and overlapped CON. Suggest: when handing a
   carnet from RED to CON, require RED's shutdown to be *acked* (terminated) before pinging CON,
   not merely requested — i.e., treat the editor→CON handoff with the same explicit-termination
   barrier as the translator→RED handoff.
4. **Source-block contamination** (Czech typed into `%%` French original) is a distinct subclass
   worth a verify-carnet check: detect Czech-only diacritics/words inside `%%`-delimited
   French-source blocks.
