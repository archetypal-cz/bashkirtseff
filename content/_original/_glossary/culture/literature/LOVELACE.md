# Lovelace

## Overview
Robert Lovelace, the aristocratic rake of Samuel Richardson's novel *Clarissa* (1747–1748), whose name became a common noun for a seducer (footnotes 030.0434.1, 034.0117.1). Marie uses it as a type, not for a person: «ce coureur, ce lovelace, ce don Juan» of Prince Tchelesky seen at the station (030.0434, 1 Apr 1875), and Collignon's warning that Audiffret «est un Lovelace» (034/1875-06-09).

Per the tagging rules, a name used as a type gets no tag, so this entry has no tagged paragraphs; it serves as a reference for the footnotes.
